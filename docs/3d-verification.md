# Three.js 3D 改造验证记录

验证日期：2026-11-12。环境：macOS x64，Intel Core i7-9750H，Google Chrome headless；画面为 390 × 844 CSS 像素，设备像素比 2，运行分辨率限制为 1.5。

## 已通过

- `npm test`：十组测试通过。包含原七组回归，以及输入、手势辅助、三维模型与资源释放测试。
- `npm run test:browser`：真实 Chrome WebGL 渲染、鼠标快速两点施法、六套主题截图、完整六关流程、窗口缩放、WebGL 上下文丢失与恢复、启动失败提示均通过。
- 独立手绘轨迹覆盖十种符咒、大小变化、倾斜、不等长笔画、反向起笔、椭圆和缺口；包含连续乱画、错误方向、相似候选、隐藏队列与失误保护反例。300 条固定随机路径用于限制无结构轨迹的误触发，仅为回归指标，不代表真实用户准确率。
- 36 种主题/关卡组合使用实际出怪时间线模拟。渲染最重模型快照，并计算全视野保守三角形上界，避免只测单一主题顺序。
- 实际微信 CJS 包在没有 `document`、`window`、`navigator` 和 DOM 构造器的 wx 测试环境中启动；强制 WebGL 1，确认两点划线消灭怪物、音效触发、前后台恢复，无启动错误。该环境使用 Chrome 提供的画布与 WebGL 实现。
